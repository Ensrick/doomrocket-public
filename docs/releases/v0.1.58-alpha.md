## Scope

The new `item_preview.png` is the unchanged 768×768 `Thumbnail_02.png` supplied
by the maintainer. Public gameplay, models, animation and audio retain the
accepted v0.1.56-alpha baseline. The load-banner version and release metadata
advance together; no experimental TEST content is promoted.

The public repository now uses the working standalone VMB 0.6.4 adaptation
of the copied Vermintide 2 Tweaker transaction. Shared ship helpers are copied
from development commit `6f026a0e770f19f854e74203e3af217096246bb2`; the original
Tweaker reference snapshot and its 34 recorded file hashes are preserved.
The public adapter requires item `3771657344`, repository
`Ensrick/doomrocket-public`, and the `-alpha` suffix.

The first v0.1.57 attempt stopped before release mutation because its old
ignore rule lacked the exact `/bundleV2/` receipt rule. A later attempt created
the GitHub candidate but VMB's independent gate refused an added unsupported
checkout attribute before calling the Steam uploader. That tag was not moved.
The broker allocated v0.1.58-alpha, which restores the working `.gitattributes`
byte for byte. Both contracts are now checked before compilation and in hosted
QA. See [tooling integration PR #5](https://github.com/Ensrick/doomrocket-public/pull/5),
[ignore-rule correction #6](https://github.com/Ensrick/doomrocket-public/pull/6),
and [accepted policy/reissue #7](https://github.com/Ensrick/doomrocket-public/pull/7).
