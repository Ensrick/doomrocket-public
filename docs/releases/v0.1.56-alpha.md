# v0.1.56-alpha promotion record

Prepared September 9, 2026. **Publication pending:** Workshop item `3771657344`
still serves v0.1.55-alpha until upload verification is recorded below.

## Selected changes

The maintainer explicitly requested stable changes on the public branch,
specifically the portrait, and publication to the existing non-TEST Workshop
item. This is a narrow port onto the accepted v0.1.55 public baseline, not a
merge of the development branch.

| Change | Provenance | Evidence and limits |
| --- | --- | --- |
| Crunch's 60x70 kill-feed portrait and deterministic atlas tooling | [Development d714e88](https://github.com/Ensrick/doomrocket-private/commit/d714e888ed4e852d86701ea5aabd09983fc040b6), shipped in TEST v0.1.64 | Asset/package checks establish the supplied image and packing. User explicitly requested promotion; no visible host/client color or orientation result has been supplied. |
| Nil/deleted-target guards in launch and reload | Narrowly ported from the target-safety work beginning in [development aeb50f8](https://github.com/Ensrick/doomrocket-private/commit/aeb50f85979b66a20ff2b2dc09436ea38b7f1c93) | [#9 host confirmation](https://github.com/Ensrick/doomrocket-private/issues/9#issuecomment-5554028509) covers the later development implementation: 38 career changes and 42 paired attack notifications. The narrower public combination must still be retested. |

The public baseline already ends bot attack notifications even when the victim
has been destroyed. The dev v0.1.62 early-return regression and subsequent
full notification rewrite are not copied. No new range floor, ammo state,
reload timing, aiming policy or audio dependency is introduced by this port.

Portrait preparation preserves the exact small PNG, its opaque background and
native dimensions; the larger 110x130 portrait is not used. See the
[portrait pipeline](../WARLOCK_PORTRAIT_PIPELINE.md) for packing and verification.

## Preserved and excluded

Body/weapon models, materials, textures, launcher hand/back placement,
loaded-warhead death drop and host-ragdoll behavior retain the accepted public
baseline. Original public damage, health, armor, trajectory, reload, sound and
projectile behavior remain unchanged.

Excluded: reposition, shoves and close-range waiting, reload preservation,
Stormvermin durability, distance-aware aiming, custom audio, and the newer
projectile/explosion lifecycle changes. TEST v0.1.65's
[relocation crash #14](https://github.com/Ensrick/doomrocket-private/issues/14)
comes from a missing network action registration; the public build contains
no reposition action. No claim is made that #14 is fixed in TEST.
