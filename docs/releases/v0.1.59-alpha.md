The public target-loss fallback and projectile trajectory are retained. Reload
and projectile tests execute the actual promoted Lua across interruptions,
deleted targets, spawn failures and reentrant explosions. Hose tests cover
endpoint scale, bone writes, numerical motion, visibility and teardown. A clean
SDK build, six verified native-material splices, complete package checks,
ragdoll regressions and hosted QA are required before publication.

## Deliberate exclusions and remaining limits

Ratling health/armor and public aiming timing are unchanged. The TEST ballistic
aim controller, visible spine aim constraint and helper calibration, grip
diagnostics, and unaccepted v0.1.79-dev firmer hose spring are excluded. The body
and launcher FBX source bytes remain the public baseline; only animation fitting
tolerances and visible walk/run states change.

The hose is cosmetic secondary physics without body/world/self collision.
Crunch's request for a firmer rest shape stays open #3. Weapon-to-hand sway #28,
near-range ground shots #6, longer aim #16, sound direction #5, crystal flame
#15, portrait frame #30, and the new balance proposal #33 remain development
work. Tight-fence retreat and rare vault animation limitations are known.

The new [alpha crash report #34](https://github.com/Ensrick/doomrocket-private/issues/34)
is unresolved. Its attachment loads v0.1.56-alpha, contains no `entity_damage`
crash stack, and ends in an explicit normal game exit. The reported Into the
Nest arena problem is accepted as an observation, but the log does not establish
its cause or prove this promotion fixes it. Do not close that issue based on
the older accepted crash reports.

A solo written observation and matching console log are enough for follow-up;
no video or second player is required. The game is not installed on the build
machine, so this release uses publication-only mode and claims no deployment
or local game test.
